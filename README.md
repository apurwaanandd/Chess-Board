# ♟️ Chess Board Game UI

## 📘 Overview

This project is a simple and elegant **Chess Board UI** created using **HTML, CSS, and JavaScript**. It displays an interactive 8x8 chessboard grid with alternating light and dark squares. The layout follows a standard chessboard design and can be extended into a fully playable chess game with move logic, piece movement, and game rules.

---

## 🧱 Tech Stack

- **HTML5** – Structure and layout of the board
- **CSS3** – Styling of the board, alternating colors, hover effects
- **JavaScript** – Used for any interactive functionality (e.g., clicking, highlighting)

---

## 🎯 Features

- ✅ Fully responsive 8x8 chessboard layout
- ✅ Alternating black and white squares
- ✅ Easily extendable for piece logic and movement
- ✅ Clean, minimalist design
- ✅ Lightweight and fast-loading
